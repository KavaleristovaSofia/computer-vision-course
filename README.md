# Computer Vision Course

Репозиторий содержит лабораторные работы по дисциплине **Computer Vision**. В рамках курса рассматриваются методы компьютерного зрения, обработка изображений и практическое применение библиотек Python.

## Лабораторные работы

| № | Название | Основные темы | Статус |
|---|---|---|---|
| 1 | Среда, данные и первая сводка | OpenCV, анализ датасета, преобразование изображений, XML-аннотации, trimap-маски, визуализация данных | Выполнена |

## Установка и запуск

Клонировать репозиторий:

```bash
git clone https://github.com/KavaleristovaSofia/computer-vision-course.git
cd computer-vision-course
```

Установить зависимости:

```bash
pip install -r requirements.txt
```

Открыть ноутбук нужной лабораторной работы в Jupyter Notebook или Google Colab.

## Результаты

Результаты выполнения лабораторных работ находятся в соответствующих директориях `labXX/results/`.

Подробное описание каждой работы, ход выполнения и полученные результаты представлены в README соответствующей лабораторной.
