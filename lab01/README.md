# Лабораторная работа №1. Среда, данные и первая сводка

**Дисциплина:** Computer Vision  
**Вариант:** 9

## Цель работы

Познакомиться с инструментами разработки в области компьютерного зрения, изучить структуру предоставленного набора данных и освоить базовые операции обработки и анализа изображений с использованием Python.

## Задачи

1. Изучить конфигурацию варианта и структуру датасета.
2. Загрузить изображения и выполнить их визуализацию с помощью OpenCV.
3. Исследовать цветовые пространства и выполнить базовые преобразования изображений.
4. Изменить размер и ориентацию изображений, сравнить результаты преобразований.
5. Изучить форматы изображений и доступные метаданные.
6. Обработать XML-аннотации и trimap-маски.
7. Построить сводную статистику по датасету.
8. Визуализировать примеры изображений с bounding boxes.

## Используемые инструменты

- **Python** — основной язык программирования.
- **OpenCV** — загрузка, обработка и преобразование изображений.
- **NumPy** — операции с массивами и пикселями.
- **Pandas** — обработка и анализ табличных данных.
- **Matplotlib** — визуализация изображений и результатов.
- **Pillow** — работа с форматами изображений и метаданными.
- **Jupyter Notebook** — интерактивная среда выполнения лабораторной работы.

## Структура работы

| Файл / директория | Описание |
|---|---|
| `solution.ipynb` | Ноутбук с кодом, анализом и выполнением заданий |
| `results/summary.csv` | Сводная статистика по датасету |
| `results/transforms.png` | Визуальное сравнение преобразований изображений |
| `results/samples_grid.png` | Примеры изображений с визуализацией bounding boxes |

## Полученные результаты

В ходе работы выполнены загрузка и исследование изображений, изучены их характеристики и аннотации, реализованы базовые операции обработки изображений.

Сформированы:
- сводная таблица характеристик датасета;
- визуализация результатов преобразований изображений;
- сетка примеров изображений с bounding boxes.

## Запуск

1. Установить зависимости из корневого файла `requirements.txt`:

   ```bash
   pip install -r requirements.txt
   ```

2. Открыть `solution.ipynb` в Jupyter Notebook или Google Colab.
3. Выполнить ячейки ноутбука последовательно.

**Примечание:** исходные данные датасета не включены в репозиторий. Для полного воспроизведения результатов необходимо иметь доступ к исходному набору данных.
